# アロマAI合格コーチ — AEAJ試験 伴走AIチャットアプリ

本番URL: https://ai.aroma8k.com

※本リポジトリはバトラン参加用の企画書（README）提出用です。
アプリ本体のソースコードは、運用中サービスの独自RAGコーパス・
診断ロジック等を含むため、別のPrivateリポジトリで管理しています。

## 1. サービス概要

**「アロマAI合格コーチ」は、AEAJ アロマテラピーインストラクター／
アロマセラピスト共通学科試験の受験者が、2人の先生ペルソナのAIコーチに
いつでも質問・相談でき、問題集に基づいた正確な解説で
合格まで伴走してもらえるサービスです。**

「AIが解説文を書くだけ」ではなく、
**「いつ・何を・どれだけやれば受かるか」を管理してくれる専属コーチ**を目指しています。
覚えさせ、忘れさせず、受かる状態まで連れていく——これが提供したい体験です。

---

## 2. このアイデアはどこから生まれたか

実在のアロマ講座の先生と協働し、先生のもとで学ぶ生徒さんに
実際に使ってもらいながら育てているサービスです。

- 講座の限られた時間では、一人ひとりの疑問にその場で全部答えきれない
- 独学の時間帯（夜・すきま時間）に質問できる相手がいない
- 問題集を解いても「なぜ間違えたか」の解説が薄く、同じ間違いを繰り返す

この「講座と講座の間の学習を誰が支えるのか」という課題を、
先生の教え方を反映したAIコーチで埋めることを目指しました。

---

## 3. 課題の整理

- **表に見えている困りごと**: 問題集で間違えた問題の「なぜ」が分からず、
  調べように公式テキストのどこを見ればよいかも分からない。
- **本当に解決したい課題**: 間違えた問題を放置したまま試験日を迎え、
  「勉強したのに受からない」状態に陥ること。
  人間は忘れる生き物なのに、独学では「いつ復習すべきか」を管理できない。

---

## 4. 想定ユーザー

**AEAJ アロマテラピーインストラクター／アロマセラピスト共通学科試験の
受験者（実在のアロマ講座の受講生を起点に運用中）。**

仕事や家庭と両立しながら学ぶ社会人が中心で、まとまった学習時間が取れず、
すきま時間での学習効率が合否を分けます。

- 使う場面: 問題集を解いた直後、通勤などのすきま時間、就寝前の復習
- 代替手段: 公式テキストの読み返し、講座での質問
  → テキスト検索は時間がかかり、講座は次回まで待つ必要がある。
  **その場でAIコーチに聞ける即時性**が置き換える理由になります。

---

## 5. 既存サービスとの違い

汎用AIチャット（ChatGPT等）でも質問はできますが、次の課題があります。

1. **正確性**: 汎用AIはAEAJの出題範囲・用語体系に準拠せず、
   もっともらしい誤答（ハルシネーション）のリスクがある
2. **伴走性**: 質問に答えるだけで、弱点管理・復習タイミングの提案までは
   してくれない

本サービスは、**問題集の解説に基づくRAG（検索拡張生成）**で回答の
正確性を担保し、**2人の先生ペルソナの対談形式**で「講座の続きを
聞いている」ような体験を提供します。

なお、知的財産への配慮として、**AEAJ公式テキストの本文はRAGコーパスに
含めず、独自に作成した問題集解説をベースに構築**しています。

---

## 6. 主な機能

3つの機能は「弱点マスタリー管理（忘却曲線スケジュール）」という
1つの背骨から生えています。各問題に「習熟度」と「次に出す日」を持たせ、
間違えたら翌日、正解したら間隔を伸ばす（3日→1週→2週→1ヶ月）。

1. **AIコーチへの質問・相談（核）**
   2人の先生ペルソナが対談形式で回答。問題集準拠のRAGで正確な解説
2. **解き直しループ**
   間違えた問題をAIが拾い、解説→その場で再出題→正解するまで回す
3. **弱点集中ドリル**
   習熟度が低い問題だけを抽出して集中出題。章×節の弱点ヒートマップ
4. **リマインド通知（LINE／メール選択制）**
   忘却曲線に基づく「次の復習日」をおすすめ提示し、本人が選ぶ。
   送りつけない・やりすぎない設計
5. **会員ログイン＋学習履歴のサーバー保存**（Supabase）
6. **月額サブスクリプション**（Stripe。AI相談回数でプランを分ける構想）

---

## 7. 収益化の考え方

「機能の多さ」ではなく「合格への効き目」に課金する設計です。

- 機能は全プラン共通、違いは**AIに相談できる回数**のみ
- AI相談の日次上限が1人あたりのAI原価の天井になるため、
  「たくさん使う人がたくさん払う＝原価と価格が一致」する健全な構造
- 規模拡大自体を目的とせず、現場（先生と生徒）に合った適正な形を保つ

---

## 8. 懸念点とその対策

- **AIの誤答リスク**: 問題集解説ベースのRAGで回答根拠を限定。
  汎用知識だけで答えさせない
- **知的財産**: 公式テキスト本文はコーパスから除去済み。
  独自作成の解説コンテンツのみを知識源とする
- **AIコスト**: 相談回数の日次上限でコストの天井を管理。
  リマインド等の定型文にはAIを使わない
- **法務**: 特定商取引法表記・プライバシーポリシー（LINE連携・
  配信停止導線）を公開前チェックリストで管理

## 9. 今後の展開

- **弱点マスタリー管理の完成**: 出題スケジュールの背骨を実装し、
  解き直し・弱点集中・リマインドを統合する
- **リマインドの本格運用**: メールで小さく検証→効果を見てLINEに展開
- **合格可能性メーター・週次レポート**: 続けたくなる仕掛けの追加
- **他講座への展開**: 先生ごとの「教え方・解説」を載せ替えられる
  仕組みにし、各講座の独自資産を育てるプラットフォームを目指す

## 10. 技術スタック

- フレームワーク: Next.js 15（App Router）+ React 19 + TypeScript + Tailwind CSS
- DB / 認証: Supabase（PostgreSQL + Supabase Auth）
- 決済: Stripe（サブスクリプション）
- デプロイ先: Vercel
- AI: Claude Sonnet 4.6（Vercel AI SDK v5 + Vercel AI Gateway 経由）
- RAG: OpenAI text-embedding-3-small（1536次元）+ コサイン類似検索
  （問題集解説ベースの独自コーパス）
