# アロマAI合格コーチ — AEAJ上位資格試験 伴走AI学習アプリ

本番URL: https://ai.aroma8k.com

※本リポジトリはBATTLE OF RUNTEQ vol.7 参加用の企画書（README）提出用です。
アプリ本体のソースコードは、運用中サービスの独自RAGコーパス・
書籍購入者認証ロジック等を含むため、別のPrivateリポジトリで管理しています。

## 1. サービス概要

**すきま時間で学び諦めかけた40〜50代の受験者が、その日の夜に「分かった」と
言える。担当講師2名の教え方を再現したAIコーチが24時間伴走します。**

対象は AEAJ アロマテラピーインストラクター／アロマセラピスト共通学科試験。
連携書籍『解いて覚える！合格問題集316問』（村田寛佳・岩本明子 著、
2026年8月4日発売）の本文にアプリとして明記されており、
書籍購入者だけが使える設計です。

## 2. 想定ユーザーと課題

想定ユーザーは「アロマを仕事にしたい」40〜50代。子育てや仕事と両立しながら、
夕飯前の30分や就寝前の布団の中というすきま時間で学んでいます。

上位資格の受験者が諦める瞬間は、点が取れない時ではなく
「なぜ違うのか分からないまま、同じ問題をまた間違えた」時です。
講座は次回まで質問できず、初歩的な質問は気後れする。
検定1級・2級には学習アプリが複数あるのに、上位資格には
アプリがほぼ存在せず、紙の問題集だけが残っている——
この空白を埋めるのが本サービスです。

## 3. 解決の仕組み

核は「24時間、遠慮なく聞ける相手がいること」の一点です。

1. **担当講師2名の教え方を再現したAIコーチ**（村田先生・岩本先生の
   ペルソナが対談形式で解説）にいつでも質問できる
2. **回答は本と講座と完全に同じ言葉** — 知識源は講師2名の講義音声と、
   その2名が作成した436問（書籍316問+アプリ独自120問）の解説のみ
3. **答えられないことには「わからない」と答える** — 誤答を信じて
   学習が狂う事故を防ぐ
4. **毎日のリマインドメール** — 途切れた学習を戻す最小の仕掛け

## 4. こだわり — 知識源を絞る

AEAJ公式テキストの本文は、コーパスに**一文も含めていません**。
取り込めば回答精度は上がりますが、知識源の出所を100%説明できる状態を
精度より優先しました。講義音声の学習利用は著者2名の同意を得ています。

同じ理由で、書籍購入者限定の登録ゲートを設けています。
誰でも使える状態は書籍そのものの価値を壊すため、
著作物を守ることをユーザー数より優先しました。

## 5. 料金プラン（Stripeで実装済み）

| プラン | 月額 | AI |
| --- | --- | --- |
| フリー（30日お試し） | ¥0 | なし |
| 問題特訓アプリ | ¥480 | なし |
| AIプラン | ¥980（AIチャット月100回） | あり |

¥480プランは実費のみで利益を乗せていません。AIプランは月100回の上限で
1人あたりAI原価に天井を作り、AIを使う顧客と使わない顧客の
原価構造を分離しています。このアプリは商品ではなく、
書籍 → アプリ → 講座 → アロマを仕事にする、という導線の一部です。

## 6. 実装済みの機能（MVP）

| 機能 | なぜ入れたか |
| --- | --- |
| AIコーチへの質問（2人の先生ペルソナ／RAG） | サービスの核 |
| 書籍購入者限定の登録ゲート | 著作権保護 |
| 会員登録・学習履歴のサーバー保存 | 質問の文脈を残す。継続の前提 |
| 管理者機能（ログイン監視・利用状況把握・アカウント削除） | 個人情報を扱う責任範囲 |
| 毎日のリマインドメール | 学習の再開点を作る |
| Stripe課金3プラン | 「払ってでも使うか」の検証 |

解き直しループ／弱点集中ドリル・章別ヒートマップ／忘却曲線リマインドは、
「弱点マスタリー管理」という1本の背骨から生やす計画で、意図的に未実装です。
「受講生は講座の外でAIに質問するのか」を確かめてから作ります。

## 7. 今後の展開

- 弱点マスタリー管理（習熟度+次に出す日。間隔反復: 翌日→3日→1週→2週→1ヶ月）
- AIによる学習サマリー付きリマインド
- 書籍の7章構成と一致した章別ヒートマップ

## 8. 技術スタック

- 言語／フレームワーク: TypeScript / Next.js 15（App Router）/ React 19
- スタイリング: Tailwind CSS
- DB／認証: Supabase（PostgreSQL + Supabase Auth、RLSでユーザーデータ分離）
- 決済: Stripe（サブスクリプション・3プラン）
- インフラ: Vercel
- AI: Claude Sonnet 4.6（Vercel AI SDK v5 + Vercel AI Gateway 経由、
  ストリーミング応答）
- RAG: 独自コーパス（講師2名の講義音声＋436問の解説）→
  OpenAI text-embedding-3-small（1536次元）で埋め込み → コサイン類似検索 →
  根拠付きで生成。根拠が無い場合は「わからない」と答える制御
- 通知: リマインドメール配信（定型文のためAI非使用）
- その他: 書籍購入者限定の登録ゲート／管理者ダッシュボード
